# Personal Knowledge Base

## Navigation

- [Cloud-First LLM Wiki on OKF](/concepts/cloud-first-llm-wiki-okf.md)

## Document groups

- `/concepts` — durable ideas and models
- `/decisions` — important choices and their rationale
- `/projects` — ongoing project context
- `/procedures` — repeatable workflows
- `/references` — curated external knowledge
- `/people` — intentionally limited personal context
- `/inbox` — temporary captures awaiting review
- `/archive` — material retained but no longer current
